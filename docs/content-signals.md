# 内容规则标签试运行

标题和摘要用于提示文章形式与疑似 AI 技术相关性，不改变来源准入、发布状态、搜索、原文或 RSS/Atom。规则不调用模型，不抓取额外正文，不修改历史快照。默认看板仍展示全部博文。

## 规则与边界

- 活动／福利：仅由标题中的明确报名、议题征集、CFP 或福利领取信号触发；避免将活动报名系统和抽奖系统误当活动。正文可能同时有技术内容，不代表低质量。
- 疑似教程：标题包含使用、安装、配置等具体操作意图。
- 疑似研究：标题摘要出现具名会议及年份、评测基准、数据集研究或论文解析等组合。
- 疑似 AI 技术：标题摘要同时出现 AI 对象与技术机制。对象包含推荐、视觉生成和检索，机制包含缓存、调度、隔离、上下文、评测和验证等。
- 待判断：没有足够组合信号；缺少摘要或正文不可用不作为不相关的证据。

文章可命中多个提示；列表只显示优先级最高的一项（活动、教程、研究、AI 技术、待判断），详情展开可看全部提示、命中片段、范围、理由和规则版本。产品名、发布公告或“论文”本身不是排除条件。它们不保证主题相关，也不认证真实工程实践。

## 可选阅读过滤

“隐藏活动／福利”默认关闭，仅影响看板及各公司列。启用后保留待判断、研究、教程与 AI 技术文章；搜索弹窗与订阅保持完整。URL 用 `hide=activities` 分享和恢复此选择，前进后退同样恢复；切换过滤重置加载批次和列内滚动。回到首页恢复全部。

## 导出、复核与回退

每次导出重新计算 `contentSignals`，附在公开文章 JSON 和站点索引中，包含 `version`、`method`、`basis`、`kinds`、`label`、`evidence` 和 `reason`。它是派生提示，不写入快照，也不复用旧规则结果。`classification.topics` 与 `advertorial` 保留原有含义。配置变化后重新导出即可，无需重采全文。

误标可通过 Issue 提供稳定 ID、原文和解释，修正规则并补回归案例。本轮没有独立人工复核，不展示准确率或 0–100 评分。不要将这套弱规则升级成收录门槛。撤销本次变更并重新发布即可回退，文章及订阅身份保持原样。
